# Trivy – 7 Days DevSecOps Learning

## 🎯 Overall Goal

The goal of this 7-day learning plan is to understand Trivy from the fundamentals to advanced DevSecOps usage and learn how to use Trivy for vulnerability, secret, configuration, filesystem, container, Kubernetes, and CI/CD security scanning.

By the end of this roadmap, I will be able to integrate Trivy into DevSecOps pipelines and use it as a security gate to identify and prevent security issues before deployment.

---

## 🛡️ What is Trivy?

Trivy is an open-source security scanner used to identify vulnerabilities, misconfigurations, secrets, and other security issues in applications, container images, filesystems, repositories, and Kubernetes environments.

---

## 📚 What I Will Learn

Throughout these 7 days, I will learn:

* Trivy fundamentals
* Trivy architecture
* Vulnerability databases
* CVEs and severity levels
* Docker image scanning
* Container image layers

* Filesystem scanning
* Repository scanning

* Configuration scanning

* GitHub Actions integration
* DevSecOps security practices
* Advanced Trivy usage

# 🔐 DevSecOps Objective

The ultimate objective is to shift security to the early stages of the software development lifecycle.

```text
Developer
    ↓
Code
    ↓
Build
    ↓
Security Scan
    ↓
Vulnerability Found?
   ↙        ↘
 YES        NO
  ↓          ↓
Fix Issue   Continue
  ↓          ↓
Rescan      Deploy
```

This helps identify security issues before they reach production.
